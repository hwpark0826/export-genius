Export Genius 자동 저장 도구 사용자 안내
==========================================

0. 들어가며
---------------
안녕하십니까, 26년 2월~6월까지 AI마케팅팀 인턴으로 근무했던 박현우입니다.
수출부스터 업무 부담 경감을 위해 Export genius 탐색 자동화 프로그램을 만들어보았습니다.

괜한 오지랖이 아닐까 걱정이 앞서지만,
조금이나마 도움이 되고자 하는 마음에서 제작한 것이니,
혹여 부족한 점이 있더라도 저의 취지를 너그러이 헤아려 주시면 감사드리겠습니다.
 
*프로그램 관련 오류 및 기타 문의사항: hwpark0826@naver.com으로 메일 전송 부탁드립니다.


1. 프로그램 소개
----------------
이 프로그램은 Export Genius의 바이어 목록을 자동으로 확인하고,
지정된 조건에 맞는 바이어 정보를 엑셀 파일로 저장합니다.
프로세스 시작과 중단은 모두 프로그램 GUI에서 진행합니다.
오류 발생 시 문의 양식은 11. 오류 문의에서 확인해주시기 바랍니다.


2. 사용 전 준비물
-----------------
- Microsoft Edge **(chrome 등 타 브라우저가 아닌 edge여야합니다)
- Export Genius 계정
- 업체 목록 엑셀
- 결과 템플릿 엑셀


3. 최초 설치
------------
1) ZIP 파일 압축을 해제합니다.
2) 폴더 안의 ExportGenius.exe를 실행합니다.
3) Windows SmartScreen 경고가 표시되면, 회사 내부 담당자에게 받은 파일이 맞는지 확인한 뒤 실행합니다.

주의:
- ZIP 파일 안에서 프로그램을 바로 실행하지 마세요.
- ExportGenius.exe만 따로 옮기지 마세요.


4. Edge 확장프로그램 등록
-------------------------
최초 한 번만 설정하면 됩니다.

1) Edge 주소창에 edge://extensions 를 입력합니다.
2) 화면의 '개발자 모드'를 켭니다.
3) '압축 해제된 확장 로드'를 누릅니다.
4) 압축을 해제한 폴더 안의 'extension' 폴더를 선택합니다.
5) Export Genius 페이지를 새로고침합니다.

주의:
- edge 확장프로그램 등록 후에는, 압축을 푼 폴더를 이동하거나 삭제하지 마세요.


5. Edge 다운로드 설정 확인
---------------------------
1) Edge 주소창에 edge://settings/downloads 를 입력합니다.
2) 다운로드 위치가 현재 Windows 계정의 기본 Downloads 폴더인지 확인합니다.
3) '다운로드 전에 각 파일의 저장 위치 확인' 옵션을 끕니다.

주의:
- 다운로드 폴더가 다르거나 저장 위치를 매번 묻도록 설정되어 있으면,
  GUI가 파일을 찾지 못해 엑셀 저장이 실패할 수 있습니다.


6. 작업 실행
-----------------
1) Edge에서 Export Genius에 로그인합니다.
2) global, import-global을 선택합니다.
3) ExportGenius.exe를 실행합니다.
4) '작업 목록 엑셀'에서 업체 목록 파일을 선택합니다.
5) '결과 템플릿'에서 템플릿 파일을 선택합니다.
6) '최종 저장 폴더'에서 결과를 저장할 폴더를 선택합니다.
7) '선택 내용 확인'을 눌러 경로와 작업 수를 확인합니다.
8) '다음: 작업 확인'을 누릅니다.
9) 실행할 작업을 체크하고 목표 저장 개수를 설정합니다.
10) '다음: 모니터링'을 누릅니다.
11) '모니터링 시작'을 누릅니다.


자동화 중에는:
- Export Genius 탭을 닫지 마세요.
- 브라우저의 검색 조건이나 페이지를 직접 조작하지 마세요.
- GUI를 추가로 실행하지 마세요.
- PC가 절전 모드로 들어가지 않게 해주세요.


7. 결과 확인
------------
최종 결과는 선택한 저장 폴더의 업체명/HS코드별 폴더에 저장됩니다.


8. 작업 중단과 이어하기
-----------------------
작업을 중단하려면 GUI의 '모니터링 중단' 버튼을 누릅니다.
가능하면 작업 관리자에서 강제 종료하지 마세요.

프로그램을 다시 실행하면 기존 엑셀 파일을 확인하고 부족한 개수만 이어서 수집합니다.


9. 프로그램 업데이트
---------------------
1) 실행 중인 GUI를 종료합니다.
2) 기존 배포본을 삭제합니다.
3) 새 배포본의 압축을 해제합니다.
4) Edge 주소창에 edge://extensions 를 입력합니다.
5) 기존 'Export Genius Helper' 확장프로그램의 '제거' 버튼을 누릅니다.
6) 확인 창이 나타나면 다시 '제거'를 누릅니다.
7) edge://extensions 화면에서 '개발자 모드'를 켭니다.
8) '압축 해제된 확장 로드'를 누릅니다.
9) 새 프로그램 폴더 안의 extension 폴더를 선택합니다.
10) Export Genius 페이지를 새로고침합니다.
11) 새 ExportGenius.exe를 실행합니다.
12) GUI와 확장프로그램의 버전이 일치하는지 확인합니다.


10. 자주 발생하는 문제
-----------------------

[프로그램이 이미 실행 중이라고 표시됨]
- 기존 GUI 창이 열려 있는지 작업 표시줄에서 확인합니다.
- 보이지 않으면 작업 관리자에서 ExportGenius를 확인합니다.

[확장프로그램 연결 안 됨]
- Export Genius 검색 결과 페이지가 열려 있는지 확인합니다.
- edge://extensions에서 확장프로그램이 켜져 있는지 확인합니다.
- 확장프로그램과 Export Genius 페이지를 각각 새로고침합니다.

[버전 불일치]
- 새 프로그램 폴더의 extension 폴더가 등록되어 있는지 확인합니다.
- edge://extensions에서 확장프로그램을 새로고침합니다.

[브라우저 작업이 시작되지 않음]
- Export Genius에 로그인되어 있는지 확인합니다.
- 검색 결과 페이지를 열고 GUI에서 다시 시작합니다.

[엑셀이 저장되지 않음]
- Edge 다운로드 폴더 설정을 확인합니다.
- 템플릿 파일과 최종 저장 폴더가 올바른지 확인합니다.
- 저장 폴더가 다른 프로그램에서 잠겨 있지 않은지 확인합니다.


11. 오류 문의
-------------
오류가 반복되면 다음 내용을 담당자에게 전달합니다.

- 업체명과 HS코드
- GUI에 표시된 오류 메시지
- 가능하면 오류 화면 캡처
- 개발자용 원문 log

로그 저장 위치:
- 압축해제한 폴더 내의 logs
- 개발자용 원문 로그는 GUI의 '원문 로그 보기'에서 확인할 수 있습니다.


12. 중요 주의사항
-----------------
- 타 브라우저가 아닌 edge 환경에서 실행합니다.
- 프로그램은 한 번에 하나만 실행합니다.
- 자동화 중 Export Genius 화면을 직접 조작하면 안됩니다.
- 프로그램 폴더의 _internal 또는 extension 폴더를 삭제하면 안됩니다.
- 정해진 형식의 파일
